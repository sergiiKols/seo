# Разбор seo: AI-читаемость сайта — что работает, что нет (с доказательствами)

Источники: evilmartians.com (доказательное исследование техник), llmstxt.org (спецификация /llms.txt v2, Jeremy Howard). Дата: 11.09.2026.
Дополняет seo-02 (там — измерение AI-видимости; здесь — внедрение читаемости).

## Постановка

ИИ-агенты читают сайты иначе, чем люди: JS-слайдеры с ценами, PDF-тарифы и навигационный мусор для них невидимы. Типичный HTML на ~80% состоит из навигации: страница сжимается с ~15 000 токенов до ~3 000 в markdown. Агент, не увидевший цену, исключает продукт из сравнения.

## Шаг 0 — без него всё остальное бессмысленно

Аудит robots.txt: дефолтные конфигурации часто блокируют GPTBot/ClaudeBot. Конвенция Cloudflare `Content-Signal:` (CC0) разделяет права: search / ai-input / ai-train.

## Шесть техник, которые работают

1. **`/llms.txt`** (спека v2): H1 — единственная обязательная секция; blockquote-резюме; H2-секции с аннотированными ссылками; секция `## Optional` — что агент может пропустить при нехватке контекста. Детали за ссылками, файл маленький. Честно: автокраулинг почти отсутствует (Adobe, 1000 доменов: 94.9% запросов файла от GoogleBot); ценность — в сценарии «человек или инструмент скормил URL модели».
2. **`.md`-роуты** — markdown по тому же URL (`/pricing.md`, `/page.html.md`). Из единого источника, иначе контент разъедется.
3. **`<link rel="alternate" type="text/markdown">`** + HTTP `Link`-заголовок (легитимно: HTML4 + RFC 7763). Ловит и DOM-краулеров, и headless-агентов.
4. **Скрытая подсказка** (`aria-hidden`, ссылка на .md) — для сценария «URL вставили в ChatGPT»: модель читает отрендеренный текст и видит подсказку.
5. **`/llms-full.txt`** — весь сайт одним файлом: в 3–4 раза больше визитов, чем llms.txt (Mintlify, в основном ChatGPT). LLM предпочитают цельные документы навигации. Для доков — да, для блога — избыточно.
6. **Content negotiation** (`Accept: text/markdown`, тот же URL): Claude Code и Cursor уже шлют этот заголовок. Сравнивать q-values, 406 при отсутствии формата, `Vary: Accept`. Это не клоакинг — формат запрашивается явно.

## Что НЕ работает (проверено)

- `<meta name="ai-content-url">`, `<meta name="llms">`, `/.well-known/ai.txt` — нет принятия, issue WHATWG закрыт «not planned».
- HTML-комментарии — ChatGPT/Claude/Perplexity вырезают их.
- Кнопки «версия для ИИ» — агенты не кликают.
- User-Agent sniffing — клоакинг, штраф Google. Альтернатива — content negotiation.
- JSON-LD/Schema.org: ChatGPT, Claude, Perplexity, Gemini пропускают данные только в JSON-LD (эксперимент SearchVIU); исключение — Copilot через Bing. Существующую разметку не удалять, но не рассчитывать на неё.

## GEO-контент (Princeton + IIT Delhi, KDD 2024, 10 000 запросов)

Прямые цитаты +43% видимости; статистика +33%; ссылки на авторитетные источники +115% для низкоранжированного контента. Работает обогащение видимого текста, не метаданные.

## Как измерять

Серверные логи — боты не исполняют JS, клиентская аналитика слепа. Трекать User-Agent и referrer (chatgpt.com, claude.ai, perplexity.ai). Контекст рынка: AI-crawling вырос >15× за 2025 (Cloudflare Radar). Валидаторы: acceptmarkdown.com, isitagentready.com.

## Минимальный комплект для наших сайтов (боты/лендинги)

1. Разблокировать AI-краулеров в robots.txt + Content-Signal.
2. Тарифы дублировать в `/pricing.md` (плоские таблицы, без слайдеров).
3. `/llms.txt` по спеке v2: резюме + секции (продукт, цены, документы, поддержка) + `## Optional`.
4. `<link rel="alternate">` на .md-версии ключевых страниц.
5. Разбор цен: это триггер 2 суда — цены в .md становятся машиночитаемыми и сравнимыми конкурентами автоматически (агент соберёт /pricing.md десяти конкурентов и сравнит).

## Что даёт seo

Кандидат в возможность «аудит AI-читаемости» (каталог, «Созревает»): чек-лист шаг 0–6 + валидаторы + логи. Активировать при первой живой задаче.
