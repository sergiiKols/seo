# tools — инструментарий мастерской

Здесь два вида файлов, и их нельзя путать.

**Скиллы** живут в `../.claude/skills/<имя>/SKILL.md` и **срабатывают сами**,
когда в работе появляется подходящая задача. Это и есть рабочий инструмент.

**Разборы** живут в этой папке. Это обоснование: откуда правило взялось, что
проверено руками, что прочитано в справке поисковой системы, почему что-то
отвергнуто. Разбор не применяется в работе — он объясняет скилл.

Правило простое: **правило, которое надо вспомнить и открыть руками, не
работает.** Если из разбора родилось применимое правило — оно обязано стать
скиллом, иначе оно только создаёт иллюзию, что правила есть.

---

## Устройство скилла

Проверено на семи скиллах соседней мастерской, повторяем формат:

```
.claude/skills/<имя>/
├─ SKILL.md        короткий: правила и порядок решения
├─ data/*.csv      каталоги и таблицы, из которых берётся одна строка
└─ scripts/*.mjs   машинные проверки, если правило меряется
```

**Короткий SKILL плюс данные в CSV, а не всё в одном файле.** Скилл читается
целиком при каждом срабатывании; таблица на 60 строк в нём — это налог на
каждый запуск. В `data/` из таблицы берётся нужная строка.

**Правило, которое машина проверяет лучше человека, идёт в скрипт, а не в
чек-лист.** У соседей это разделение дало главный выигрыш: машина меряет факты,
человек тратит внимание на то, что измерить нельзя.

## Шапка разбора

```
# <название> — разбор

Отчёт от <дата>. Статус: <разобран по исходникам / проверен запросами /
не проверялся>. Вердикт: <принят / отклонён / принят частично>.

Источник: <ссылка> · Лицензия: <какая>
```

Статусы: **проверено** (запускали руками), **принято**, **отклонено**,
**не подтверждено** (прочитано, но не проверено).

Отклонённые разборы **не удалять**: без записанной причины отказа через три
месяца тот же инструмент разбирается заново с нуля.

---

## Особое требование для SEO

**У каждого факта — дата проверки.** Поисковые системы меняют правила без
объявления. «Google не учитывает мета-ключевые слова» — верно, но проверено
когда? Утверждение без даты в этой папке считается непроверенным.

**Расхождение Яндекса и Google оставлять в тексте.** Не сводить к одному
правилу «в среднем». Разница между системами — это и есть содержание работы.
