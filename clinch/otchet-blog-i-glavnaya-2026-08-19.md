## 2. Сквозные проблемы — одинаковые на всех одиннадцати страницах

**1. Нет микроразметки, canonical и Open Graph.** На всех 11 страницах ноль
`application/ld+json`, ноль `rel="canonical"`, ноль `og:`-тегов. У
правообладателя бренда (clinch.ru) Schema.org есть — Product, BreadcrumbList,
AggregateRating. Для статей нужны `Article` и `FAQPage` (блоки «вопрос-ответ»
на страницах уже есть — размётка даст расширенный сниппет бесплатно).

**2. 78% отслеживаемых запросов не встречаются на сайте дословно.** Из 306
запросов точное вхождение есть только у 67. Ещё 74 запроса не покрыты даже
по словам.

**3. 31 запрос уже имеет позицию, но точного вхождения нет.** Это самые дешёвые
правки: страница уже релевантна, не хватает дословной фразы. Например,
«купить перчатки для бокса» (46 показов, 27 место), «для бокса экипировка»
(19, 26 место), «купить вещи для бокса» (9, 27 место).

**4. Изображения без alt.** В каждой статье ровно два изображения без
атрибута — типовой элемент шаблона. На главной **14 из 23**.

**5. Перестановки слов приняты за разные фразы.** «Спортивный костюм беларусь»
и «костюм спортивный беларусь» — оба по 252, это одно число Вордстата на две
словоформы. Дописывать в текст все перестановки не нужно и вредно.

## 5. Проверено снимком выдачи — три поправки

Снимок Топвизора от 19.08 (643 запроса × 50 URL) закрыл вопросы из этого
раздела и опроверг две гипотезы. Полный разбор — в
[`serp-analiz-2026-08-19.md`](serp-analiz-2026-08-19.md).

**Поправка 1. Размерный хвост перчаток не вернуть таблицей унций.** Топ-5 по
«перчатки для бокса 14 унций», «8», «16» — Ozon, Wildberries, Яндекс.Маркет,
Avito, Спортмастер. Это товарные запросы, их держат витрины маркетплейсов, а
не статьи. Таблица унций полезна для информационных запросов — там мы 8-е,
11-е, 13-е, — но размерные товарные ею не берутся.

**Поправка 2. Каннибализации нет.** Проверил все 643 запроса: ни по одному в
топ-50 не стоят две наши страницы. Заглавная «Форма для бокса» не проигрывает
дочерним — её просто нет в выдаче.

**Поправка 3. Главная — самая ранжируемая страница сайта:** 33 запроса из 643,
больше любой статьи. Её переписывание переезжает с девятого места приоритетов
на первое.

**Правило, которое видно в цифрах:** пока в топ-10 не больше двух
маркетплейсов, мы входим в десятку в 13–31% случаев; с трёх и больше — в 2%.
Все 26 наших позиций в топ-10 стоят на запросах с 0–2 маркетплейсами.
