## Что осталось

Ничего из **плана работ** по этой странице. Осталось из более раннего
аудита 05.08 — то, что в план не попадало:

- **Неразрывные пробелы: 57 пропущенных.** Типографику не начинали вообще:
  в коде страницы ноль `&nbsp;` и ноль символов U+00A0. Против 52 на 12.08 —
  рост только за счёт добавленного вводного абзаца.
- **Нет `FAQPage`.** В JSON-LD только `WebPage` + `Article` +
  `BreadcrumbList`. Материал для 3–4 вопросов на странице фактически есть
  («агент собирает или помогает?», «что с Claude Code / Codex?»),
  а у главной и у страницы сравнения FAQ-разметка уже стоит.
- **Ноль иллюстраций при пяти сравнительных таблицах.**
- **Мелочь: лишний редирект-хоп.** В сыром HTML осталась ссылка
  `href="/knowledge-base"` (без `.html`), которая отдаёт `301`. В рендере
  та же ссылка ведёт напрямую на `/knowledge-base.html` — расходятся
  пререндер и клиентский рендер.
- **Остаток семантики по этой странице** (стратегия, п. 5) — внедрена 1 фраза
  из 5: не добавлены «информационная система и искусственный интеллект»
  (1 986), «автоматизация рутинных задач» (1 759), «платформа больших
  данных» (1 114), «искусственный интеллект и интеллектуальные
  информационные системы» (267).
- **Небольшая просадка объёма**: сыро 486 → 476 слов, рендер 1405 → 1368.
  Ниже порога значимости, но при следующем замере стоит убедиться, что тренд
  не продолжится.
